問題番号(ABC201A - Tiny Arithmetic Sequence)
AtCoder の等差数列判定問題を解説します。

## 問題概要

長さ 3 の数列 $A = (A_1, A_2, A_3)$ が与えられます。  
この数列 $A$ の要素を並び替えて、等差数列（$A_3 - A_2 = A_2 - A_1$）にできるかどうかを判定する問題です。

- **制約**: $1 \le A_i \le 100$（入力はすべて整数）
---

## 考え方

数列の要素数が 3 個と非常に少ないため、以下のアプローチで簡単に解くことができます。

1. **ソート（昇順に並び替え）する**
   - 3 つの数字を小さい順（$A_1 \le A_2 \le A_3$）に並び替えます。
2. **公差（隣り合う差）を比較する**
   - 小さい順に並べた場合、等差数列になる条件は **「(中央 - 最小) と (最大 - 中央) が等しいか」** となります。
   - 式にすると `$A_2 - A_1 == A_3 - A_2$` です。

---
## 解答例 (Python)

```python
# 入力を受け取り、整数に変換してリストにする
A = list(map(int, input().split()))

# 小さい順にソートする
A.sort()

# 等差数列の条件を満たすか判定
if A[1] - A[0] == A[2] - A[1]:
    print("Yes")
else:
    print("No")
